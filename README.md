# TravelHub

Can cai Node.js/npm va .NET SDK 10. Cau hinh MySQL theo [huong dan backend](backend/README.md).

Cai thu vien frontend lan dau:

```powershell
npm --prefix frontend install
```

Tu thu muc goc du an, chay ca frontend va backend bang mot lenh:

```powershell
npm run dev
```

Mo http://localhost:3000. Backend chay tai http://localhost:5108.
Nhan Ctrl+C de dung ca hai. Neu mot tien trinh dung, tien trinh con lai cung duoc dung.
